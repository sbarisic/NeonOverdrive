Rajdhani SemiBold by Indian Type Foundry, bundled under the SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/rajdhani

The WebAssembly assembly embeds the TTF and rasterizes a 48 px atlas once at startup. Trilinear filtering and mipmaps keep HUD and world labels smooth under camera scaling and browser pixel density changes. No remote font request is required at runtime.
